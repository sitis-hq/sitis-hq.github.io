Privacy policy

Last updated: October 26, 2026.

Who uses Sitis

Sitis is used only by its owner, for the owner's own YouTube channels. Access to a channel is granted by the channel's owner through Google's consent screen and can be revoked at any time at myaccount.google.com/permissions.

What data is accessed

With the access granted, Sitis uses the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API to upload and edit the channel's videos, thumbnails and captions, to read and answer comments, and to read the channel's analytics and revenue reports.

How it is stored

The authorization token is stored encrypted on the owner's own server. Analytics and video data are kept there to plan and produce the channel's content. Nothing is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Sitis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Revoking access stops all use. Data kept on the owner's server is deleted on the owner's request.
